

# SmartForm Filler 1.0
## Quick Start Guide

### Installation

1. Open `chrome://extensions` in Google Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select the SmartForm Filler extension folder.
4. If you have already installed an earlier version, click the **Reload** icon on the extension card to update it.

### Getting Started

**1. Set Up Your Profile**

Open the extension popup and click **Edit Profile** to access the Options page. Enter your personal information and upload your passport-size photo.

**2. Visit a Webpage with a Form**

Navigate to any webpage containing a form. When SmartForm Filler detects form fields, the extension icon will turn teal and display the number of detected fields.

**3. Review and Autofill**

Click the SmartForm Filler icon to open the popup. Select your preferred profile, review the detected fields, and click **Fill** to automatically populate the form.

### Keyboard Shortcut

Press **Alt + Shift + F** to quickly trigger the autofill process.
